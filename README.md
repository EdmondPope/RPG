A game made in Godot where you play as a guy desperately running from an immortal snail across a massive tileset world. The game features smooth top-down movement, Y-sorting for depth, and collision systems that allow the player to interact naturally with the environment while navigating through a long continuous path filled with obstacles, scenery, and dangerous areas.

The world is built using detailed tilesets with forests, roads, buildings, fences, abandoned locations, and narrow pathways that force the player to constantly keep moving while planning the safest route forward. The immortal snail slowly follows the player at all times and can never truly be stopped, creating constant tension as it crawls closer no matter how far away the player gets.

Players must avoid obstacles, manage movement carefully, and travel through the endless path while the environment becomes increasingly difficult and unpredictable. The long map encourages exploration and survival while maintaining pressure from the unstoppable snail that is always searching for the player.

The project focuses on atmosphere, movement, survival tension, and world design while showcasing tile-based level creation, Y-sorting systems, collision handling, enemy AI behavior, and continuous map traversal inside the Godot engine.
